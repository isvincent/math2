給學生的學習指引：如何稱霸本單元？

學習線性規劃需要循序漸進，建議你依照以下四個步驟來使用本網站：

Step 1. 建立圖形直覺

先閱讀單元 1~2，學會把「大於、小於」的不等式轉換為平面上的區域，並透過互動畫布觀察平行線的平移。

Step 2. 掌握核心解法

進入單元 3~5，重點學習如何畫出「可行解區域」，並熟練運用「平行線法」與「頂點法」尋找極值。

Step 3. 避開考題陷阱

大考最愛考變化題！詳讀單元 4 了解「無界區域」，並在單元 7、8 理解「多重解」與「整數解」的進階觀念。

Step 4. 實戰演練與測驗

觀念通了以後，請前往上方的「課本題庫」看詳解，接著在「練習區」動手算，最後到「測驗區」檢驗學習成果！

1. 📏 平行直線系 (Systems of Parallel Lines)

想像一下，我們有一條直線 x - y = k。如果我們把它上下左右推動，它的傾斜程度（斜率）完全不會變！這群斜率相同、互相平行的親戚們，就稱為「平行直線系」！🚀

🎮 體驗平行平移

觀察直線 x - y = k

改變 k 值會改變直線的 x、y 截距，讓直線產生平移效果，但傾斜程度 (斜率) 永遠保持不變。🪄

2. 🎨 二元一次不等式的圖形

一條直線 ax + by = c 就像是一把剪刀 ✂️，會把整個平面切成兩半（兩個半平面）！

  • 包含邊界：若有等號（如 ≤, ≥），圖形包含這條線本身，畫成實線 🧱。
  • 不含邊界：若無等號（如 <, >），圖形不包含邊界，畫成虛線 👻。
  • 判斷區域：隨便找一個點（例如原點 (0,0)）代入算算看，如果成立，區域就在那邊！🎯

x + y ≤ 2 🟢

包含邊界 (實線)
代入 (0,0) => 0 ≤ 2 (成立)
故區域包含原點。

x + y > 2 🔴

不含邊界 (虛線)
代入 (0,0) => 0 > 2 (不成立)
故區域在不含原點的另一側。

3. 🎯 尋找最佳解 (目標函數極值)

當我們把很多個不等式畫在一起，它們共同重疊的區域就叫做「可行解區域」🏰。在這個區域內，我們要找出能讓目標函數（例如利潤 P = x + 3y）達到最大或最小的點！

🏆 解題兩大心法：
👉 📏 平行線法：把目標函數想成一根掃把（可以滑動的直線），在圖上掃描，最後離開區域的那個點，就是極值發生的地方！👀
👉 👑 頂點法：如果極值存在，必定發生在多邊形的「頂點」上。只要算出所有交點，一個一個代入比大小就可以了。🔢

限制條件

x + 2y ≤ 6

2x + y ≤ 6

x ≥ 0, y ≥ 0

目標函數

k = x + 3y

k = 0 k = 12

試著找找看，紅色直線離開藍色區域時，最後碰到的頂點座標是多少？

4. 高二段考必考陷阱：什麼時候會「沒有」最佳解？

在高中數學的大考中，不是每一個線性規劃問題都能順利找到最大值和最小值！請特別留意以下兩種常考的陷阱情況：

陷阱一：無界的區域 (Unbounded Region)

如果可行解區域沒有被完全封閉（例如一直往右上方無窮延伸），此時目標函數可能會有最小值，但最大值會是無限大（不存在）。

💡 破解法：遇到無界區域時，千萬別只依賴頂點法！請用「平行線法」推演一次，最能清楚看出直線是否會一直無窮盡地平移下去。

陷阱二：空集合 (No Feasible Region)

如果限制條件彼此互相矛盾（例如：要求 x+y ≥ 5 同時又要求 x+y ≤ 2），那麼根本畫不出共同的交集區域。

💡 破解法：沒有可行解區域，當然就沒有最佳解！解題第一步一定要畫圖確保「交集區域存在」。

5. 考前統整：我該用平行線法還是頂點法？

這是高二學生最常問的問題。其實兩種方法各有千秋，大考時最好兩者搭配使用：

解題方法 優點 (什麼時候用) 缺點與盲點 (要注意什麼)
📍 頂點法 計算簡單暴力，只要把所有交點解出來，代入比大小即可。非常適合「封閉的多邊形區域」。 當區域是「無界」時，頂點法可能會給出錯誤答案！此外，單純代入數字無法判斷「多重最佳解」。
📏 平行線法 幾何意義最清晰！能完美解決無界區域、找出無限多組解，這是大考真正想測驗的數學觀念。 需要畫圖比較精準，如果只靠肉眼判斷斜率大小容易看錯（建議配合斜率數值分析）。

6. 🏭 現實生活中的線性規劃應用

線性規劃最早於 1920~1930 年代發展，如今廣泛應用於物流路線設計 🚚、商品庫存管理 📦、資源最佳化分配等領域。讓我們看一個工廠生產的經典例子：

🏭 鍛冶工廠的利潤最大化問題

情境：工廠使用紅色、黃色礦砂來生產 A、B 兩種合金。

  • 生產 1 公斤 A 合金：需紅色礦砂 50g、黃色 40g。每公斤利潤 50 元。
  • 生產 1 公斤 B 合金：需紅色礦砂 20g、黃色 40g。每公斤利潤 30 元。
  • 資源限制：目前庫存只有紅色 900g，黃色 1200g。

【數學模型建立】

設生產 A 合金 x 公斤，B 合金 y 公斤。

目標函數 (總利潤)： P = 50x + 30y

限制條件 (紅砂)： 50x + 20y ≤ 900

限制條件 (黃砂)： 40x + 40y ≤ 1200

隱含條件： x ≥ 0, y ≥ 0

解法提示：透過畫出不等式圖形找到各個頂點，代入 50x+30y 比較，即可推算出最佳的生產配比！

7. 進階探討：多重最佳解 (無限多組解)

在某些情況下，最佳解可能不只一個頂點！當目標函數的直線斜率剛好與可行解區域的某條邊界斜率相同時，平移的直線會與該邊界完全重疊。

  • 如果最大值出現在頂點 A 與頂點 B 兩處，這代表什麼？
  • 這代表連接 A、B 兩點的整條線段上的每一個點，代入目標函數都會得到相同的最大值！
  • 這種情況我們稱為具有「多重最佳解」或「無限多組最佳解」。

判斷技巧

若將兩個相鄰的頂點代入目標函數得到相同極值，即為多重解發生！

8. 現實的限制：整數解 (格子點)

在實際應用中，許多變數不能是小數。例如：生產的汽車數量、安排的員工對數、購買的商品件數等，這些都必須是整數。

尋找格子點

若題目限制 x, y 必須為整數，我們要在可行解區域內找出座標皆為整數的點（稱為格子點）。

例題：求滿足 3x + 2y ≤ 6, x ≥ 0, y ≥ 0 的非負整數解有幾組？

檢驗 x = 0 時: 2y ≤ 6 => y 可為 0, 1, 2, 3 (共 4 組)
檢驗 x = 1 時: 3 + 2y ≤ 6 => 2y ≤ 3 => y 可為 0, 1 (共 2 組)
檢驗 x = 2 時: 6 + 2y ≤ 6 => 2y ≤ 0 => y 可為 0 (共 1 組)
結論：共有 4 + 2 + 1 = 7 組整數解！

9. 學以致用：學完線性規劃，在生活中有什麼用？

線性規劃不只是考卷上的數學題，它是現代社會運作的幕後推手。身為高中生，你也可以將這套思維應用在生活中：

零用錢與時間管理

你有固定的零用錢和週末時間（限制條件），想要兼顧「娛樂滿足感」和「讀書進度」（目標函數）。你可以透過設立不等式，找出最佳的時間與金錢分配！

飲食與健康控制

想減脂增肌，必須達到每日蛋白質需求，但又不能超過卡路里上限（限制條件）。在預算有限下，該買多少雞胸肉、多少豆漿，才能達到最省錢的健康組合？這就是標準的最小化成本問題！

遊戲資源調度

在策略遊戲中，你有固定的金幣與木材，要決定生產多少步兵和騎兵來達到最強戰鬥力。每一個單位的消耗與戰力貢獻都不同，這本質上就是一個整數線性規劃問題！

進階與延伸學習

當變數從兩個變成幾百個？當電腦要如何在一秒內解出最優解？讓我們一窺真實世界中，線性規劃的終極樣貌！

三維與多維的線性規劃

在課本中，我們只處理了 $x, y$ 兩個變數，因此可行解區域是一個平面的「多邊形」。
如果我們有 $x, y, z$ 三個變數呢？

  • 限制條件變成平面： 每個不等式 $ax+by+cz \le d$ 都不再是線，而是一刀切過立體空間的「平面」。
  • 可行解變成多面體： 所有的限制條件交集起來，會形成一個像寶石一樣的「多面體 (Polyhedron)」。
  • 頂點法依然成立： 最神奇的是，極值依然會發生在這個立體寶石的「頂點」上！

電腦如何解題？單形法 (Simplex Method)

在真實的商業應用（如航空公司的航班調度），變數可能高達數萬個！人類無法畫出幾萬維的圖形來找頂點，那電腦是怎麼解的？

George Dantzig 的偉大發明

1947 年，美國數學家丹齊格發明了「單形法」。它的演算法邏輯非常直觀：

  1. 隨便找到多面體上的一個「頂點」作為起點。
  2. 觀察相鄰的邊，沿著能讓目標函數「增加最快」的邊走，移動到下一個頂點。
  3. 重複這個過程，直到周圍沒有任何相鄰頂點能讓結果更好為止。此時的頂點即為全局最佳解！

一體兩面：對偶理論 (Duality)

數學家發現了一個驚人的事實：每一個「求最大利潤」的線性規劃問題，背後都隱藏著一個「求最小成本」的鏡像問題！

主問題 (Primal) 在資源有限下，
如何分配生產以達到最大利潤？
對偶問題 (Dual) 如果競爭對手想買下所有資源，
他應如何定價才能使收購成本最小？

強對偶定理 (Strong Duality Theorem):
主問題的最大利潤 永遠精準等於 對偶問題的最小成本！

當小數不被允許：整數規劃 (Integer Programming)

在線性規劃中，我們算出來的最佳解常常是小數（例如：生產 3.7 台車）。但在現實中，我們無法生產「半台車」，這時我們就必須加上「變數必須為整數」的條件，這稱為整數規劃。

直覺的陷阱：四捨五入通常是錯的！

許多人以為算出來是 3.7，只要四捨五入變成 4 就可以了。但實際上，(4, 2) 可能根本不在可行解區域內！

加入整數條件會讓問題的難度暴增（在資訊科學中這屬於 NP-hard 難題），著名的「背包問題 (Knapsack Problem)」與「旅行推銷員問題 (TSP)」都屬於此類。

牽一髮動全身：敏感度分析 (Sensitivity Analysis)

找出最佳解後，老闆通常會問下一個問題：「如果我再多給你 1 公斤的紅色礦砂，我們的利潤可以增加多少？」這就是敏感度分析在研究的事。

  • 影子價格 (Shadow Price)：
    多增加 1 單位的某資源，能讓目標函數（如利潤）增加多少。如果影子價格是 10 元，代表你最多只能花 10 元去買這 1 單位的額外資源，否則就會虧本！
  • 容許變動範圍：
    市場價格天天在變。如果 A 合金的利潤從 50 元跌到 45 元，我們原本算出來的最佳生產計畫還適用嗎？敏感度分析可以告訴我們，只要價格落在某個區間內，最佳解的「頂點位置」就不會改變。
